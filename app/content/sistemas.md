# Sistemas Lineares

## Definição

Um **sistema de equações lineares** é um conjunto de equações do tipo
$a_1x_1 + a_2x_2 + \dots + a_nx_n = b$, todas com as mesmas incógnitas.
Pode ser escrito na forma matricial $Ax = b$, onde $A$ é a matriz de
coeficientes, $x$ o vetor de incógnitas e $b$ o vetor de termos
independentes.

## Propriedades principais

- Um sistema pode ter **solução única**, **infinitas soluções** (sistema
  indeterminado) ou **nenhuma solução** (sistema impossível).
- Geometricamente, cada equação com 2 incógnitas representa uma **reta**; a
  solução do sistema é o(s) ponto(s) onde as retas se intersetam. Com 3
  incógnitas, cada equação é um **plano**.
- Métodos de resolução: eliminação de Gauss, regra de Cramer (quando
  $\det(A) \neq 0$), forma matricial $x = A^{-1}b$.

## Quando se usa (aplicações)

Problemas de otimização, misturas, circuitos elétricos, balanceamento de
equações químicas, e qualquer situação com várias restrições lineares
simultâneas.
